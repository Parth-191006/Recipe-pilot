# Golden corpus for the offline ingredient parser.
#
# One ingredient line per row, then the outcome the parser must produce,
# separated by " | ". The test (test/ingredient_corpus_test.dart) reads this
# file and asserts every row, so a rule change that quietly breaks a line
# someone actually cooks from fails the build instead of shipping.
#
#   clean     -> exactly one item, understood confidently (never "needs review")
#   clean:N   -> exactly N items, all understood
#   review    -> at least one row is flagged "Needs review" (never guessed)
#   review:N  -> N items, at least one flagged
#   ignored   -> zero items (section headers and other recipe prose)
#
# Lines are written the way published recipes write them: mixed metric and
# imperial, bullets, numbering, fractions, unicode glyphs, prep commas.
